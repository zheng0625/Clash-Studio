# Clash Studio UI 布局工坊

安装前端依赖后，在项目根目录运行 `scripts/start-ui-workshop.ps1`（Windows），或在 `frontend` 中运行 `pnpm dev --port 5178`。浏览器打开 http://127.0.0.1:5178/ui-editor.html 。

1. 左侧切换七个页面。画布直接加载现有 Vue 组件，使用隔离的示例数据。
2. 使用“选择 / 拖动”点击元素。右侧调整尺寸、留白、颜色、圆角、网格列等 CSS 属性。尺寸需要单位，如 `24px`、`80%`、`auto`；网格可输入 `2fr 1fr`。
3. 拖动按 4px 吸附，使用相对定位偏移。要让其他卡片跟随重新布局，请选择父容器调整 grid/flex，或使用“前移 / 后移”修改排列顺序。文字和小控件可以直接点击选择，图层列表主要展示容器。
4. “父级”可逐层选中整个卡片或容器。“交互预览”允许使用导航、设置弹窗等原有交互。示例数据不包含私人订阅，不会启动代理内核；写操作不提交。
5. 修改会自动保存在当前浏览器的本地存储。Ctrl+Z 撤销，Ctrl+Shift+Z 重做；右侧输入框使用自身的文字撤销。
6. 调整完成，点击“导出布局工程”，保存 `clash-studio-ui.layout.json`，交由开发者整合。还可导出 `clash-studio-ui.css`；当前页 HTML 快照用于静态查看，不保留 Vue 交互。

布局工程支持导入继续编辑。各页样式通过 `.desk[data-ui-page]` 限定。CSS 中的 DOM 路径对应当前项目版本；组件结构后续发生变化时，应重新核对选择器。自定义 CSS 可使用媒体查询适配不同窗口。导出的样式尚未自动写入正式客户端，确认设计后再整合。

开发：在 `frontend` 中运行 `pnpm dev --port 5178`。`pnpm build` 同时产出原有入口、`ui-editor.html` 和 `ui-preview.html`。预览入口单独拦截请求，不依赖后端。
