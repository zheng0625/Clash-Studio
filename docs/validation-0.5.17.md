| 检查 | 结果 |
| --- | --- |
| Python 后端测试 | Windows / Linux 各 50 项通过 |
| Rust 测试 | Windows 6 项、Linux 7 项通过 |
| 前端 | TypeScript 检查与生产构建通过 |
| 桌面程序 | Windows / Linux release 构建通过 |
| 停止时选择节点 | 不启动主内核或独立测速内核，按订阅保存，重启后恢复 |
| 打包后实际代理 | 三个包的内置 Python 与真实 Mihomo 完成本地 HTTP 200、在线切换与停止再启动恢复 |
| Windows 安装 / 卸载 | 安装标记、开始菜单、注册项正常；卸载保留额外用户文件 |
| Linux 原生启动与自启 | Ubuntu 虚拟机原生窗口、desktop 文件、gio 再次启动和正常退出通过 |

600 节点 Edge 测试中，连续 5 次点击的下一帧选中反馈约 3–9 毫秒，合并为 2 次后台提交，最终选择正确保存。为检查连续点击，测试人为延迟接口响应 900 毫秒。这是该测试环境的结果，不是所有设备的性能保证。

自动化流程没有为本版本新增 Windows UAC/TUN 原生窗口点击验收；维护者确认的使用验证与自动检查分别记录。Linux 构建基线为 Ubuntu 22.04 x64，文件名保留 preview1 标记。Windows 包未签名并依赖系统 WebView2；Linux 依赖桌面 GTK/WebKit。
