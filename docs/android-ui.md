# Android ARM64：界面重构第一阶段

本阶段调整 `frontend` 的手机布局，沿用现有 Vue 页面和数据接口。后续已增加独立的 APK 界面验证工程，见 [Android Studio 接入记录](android-build.md)。Android VPN 服务、前台服务和 ARM64 代理内核仍未集成；界面验证成功不代表设备可以运行代理。

## 界面

- 宽度不超过 760px 时显示五栏悬浮液态玻璃 Dock：概览、代理、订阅、连接、设置；保留透明模糊、高光边缘、圆角和选中指示。触控设备的短横屏（宽度不超过 960px、高度不超过 500px）也使用此布局。
- 设置页提供模块分流、配置工作台入口；两个工具页之间可切换或返回设置。离开编辑器时沿用未保存草稿确认。
- 概览突出内核运行操作，页面采用单列卡片；代理节点列表、连接详情、设置表单适配小屏。连接详情保留策略链和传输量。
- 导入订阅、编辑模块和确认窗口使用底部面板；设置窗口适配视口，内容可滚动。
- 适配顶部和底部安全区、动态视口高度及触屏操作。调色沿用现有浅色、深色及用户自定义主题。
- 桌面尺寸继续显示原有 Dock。

## 平台能力区分

Android 根据平台接口或 Android User-Agent 识别，不以手机屏幕宽度判断系统。安卓界面隐藏桌面 TUN 模式、协议栈、管理员权限、桌面系统代理选择和托盘驻留设置；当前只展示本地代理端口及 VPN 尚未接入的状态。应用配置请求也强制使用 `tun: false` 和 `proxy_mode: manual`，避免沿用桌面保存的 TUN 选项。桌面端继续提供原有功能。

Android 的全设备流量接管需单独实现 `VpnService`、用户授权及服务生命周期；其本地接口同样可以是 TUN，但不能直接套用桌面管理员授权和路由管理。参考 [Android VPN 开发文档](https://developer.android.com/develop/connectivity/vpn)。

## 验证（2026-10-24）

- `pnpm run build`：Vue / TypeScript 检查和生产构建通过；构建仍提示 Tauri API 同时被静态和动态导入。
- Edge 无头浏览器、模拟触控：320、360、393、430、740px 宽度下遍历七个页面及配置编辑器六个标签页；852 × 393 横屏、深色主题、空订阅、缩小到 420px 高度的弹窗、桌面导航切换及液态玻璃 Dock 几何与模糊效果，共 72 项检查通过，无横向溢出或浏览器脚本异常。
- 额外验证未保存草稿时取消离页、确认离页，以及无订阅时启动按钮禁用。
- 验证 Android 首页与设置隐藏桌面模式和权限入口，旧 TUN 偏好不会让应用请求启用 TUN / 系统代理；切回桌面平台后仍显示 TUN 入口。
- 数据接口均使用测试夹具；没有读取真实订阅、启动真实内核或更改设备网络。
- 检查脚本、结果及预览图保存在工作区 `artifacts/android-ui/`。

## 后续接入

Android 宿主现已提供安全区、键盘视口、返回键、文件选择与原生消息桥，并接入实际订阅管理和本地存储，见 [主要功能开发记录](android-features.md)。VPN 授权、ARM64 代理内核、前后台服务与联网生命周期仍需实现和真机验收。
