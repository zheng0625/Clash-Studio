# Clash Studio UI 第二轮实施与验证

日期：2026-10-26。接续《UI第一轮实施与验证-2026-10-26.md》，本轮落实 UI-07 设置查找与分组、UI-13 分流规则编辑，并补齐这些流程的保存反馈。本记录只陈述实际完成和验证的内容。

## 实施内容

### 设置

- 按“连接与代理、DNS 与局域网、外观与语言、应用行为、内核与诊断”提供快速定位和关键词搜索。应用行为按平台提供：Android 显示权限入口，桌面宿主显示驻留／自启；普通网页预览不提供桌面宿主设置。
- 支持 DNS、端口、局域网及中英文相关关键词；无结果时可清除搜索。DNS／局域网搜索结果可直接打开详细设置。
- 搜索使用显示／隐藏保留现有组件实例，不清空表单；从“内核与诊断”可切换到运行日志。
- 将语言放到外观分组；为模块分流、配置工作台补充用途说明。
- 端口编辑新增未保存追踪，与网络设置分别汇总；保存网络设置不会清除另一份未保存的端口输入。刷新当前设置不会重置未保存标记。
- Android 详细设置中的保存按钮与实际语义保持一致，使用“保存设置”。

### Android 分流

- 默认以“实际优先级、匹配条件、启用状态、目标出口”展示规则摘要，点击编辑单条。支持规则／出口／应用名称搜索，匹配类型与启用状态筛选。
- 筛选只改变展示，序号保留实际优先级；上移／下移操作始终针对完整列表中的相邻位置，保存时不携带 UI 内部标识。
- 单条编辑先修改独立草稿，“完成编辑”回填列表后仍需保存；取消输入、放弃全部修改、重新加载均有相应保护。无结果时可清除筛选。
- 应用规则可搜索已安装应用名称或包名，选择后回填包名。应用列表接口只提供名称和包名，本轮未增加应用图标，也未增加拖动排序；保留可访问的上移／下移按钮。
- 固定底部操作条区分“未保存”“保存失败”“已保存待应用”“已保存”；应用操作复用现有运行接口和版本确认逻辑，失败可重试。
- 保存失败保留当前输入，支持重试和确认丢弃后重新加载。请求返回时校验所属页面／订阅，避免迟到响应覆盖新的列表。
- 编辑器固定标题与底部操作，中间字段滚动；设置初始焦点、Tab 循环、Escape、关闭后焦点归还。Android 返回键优先处理打开的原生弹窗，规则输入未完成时先提示保留／丢弃。
- 压缩手机设置／分流页的重复说明、顶部应用入口和状态区，底部保存条避开导航。

### 隔离预览

`ui-preview.html?platform=android` 增加 24 条示例规则、3 个示例应用和权限读取示例。预览仍拒绝写请求；自动化验证另行在独立浏览器上下文注入保存／应用的模拟响应，未修改真实订阅或启动 VPN。

## 验证结果

| 维度 | 实际结果 |
| --- | --- |
| 类型与生产构建 | `pnpm --dir clashstudio/frontend build` 通过；Tauri core 的静态／动态导入分块提示仍存在 |
