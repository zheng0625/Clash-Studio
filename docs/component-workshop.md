# 组件工坊

在 `frontend` 目录运行 `pnpm dev:components`，打开 http://127.0.0.1:5181/ui-components.html 。无需启动 Python、Mihomo 或 Tauri。

## 安卓组件工坊

在 `frontend` 目录运行 `pnpm dev:android-components`，打开 http://127.0.0.1:5181/ui-android-components.html 。桌面工坊与安卓工坊共用同一个预览服务，已启动时可直接从侧栏切换。原有 `ui-android.html` 继续作为安卓主题编辑器使用。

安卓目录包含概览、订阅、代理、连接诊断、精确分流、设置与日志六个页面，共 47 个原位目标。直接渲染正式 `Client.vue`，通过本地平台样例启用安卓移动导航、VPN 控制、精确分流和权限设置；没有为安卓复制组件模板。安卓正式页面未提供的内存卡片、模块分流和配置工作台不列入目录。

默认视口为 393 × 873 CSS px。预设包含 360 × 780、393 × 873、430 × 932、780 × 412 横屏和 1024 × 768 平板；选择预设同时更新宽高，也可自由输入或拖动画布尺寸。移动布局等级由正式 `mobile-tier.ts` 判断，自动选中在页面切换动画结束后进行。

支持与桌面工坊相同的图层选择、拖动和八方向尺寸调整、中心 X/Y 定位、刻度和网格、坐标 CSV、布局 JSON/CSS 导出及验收锁定。安卓仅提供原位预览，布局使用 `clash-android-component-layout-v1`，验收记录使用 `clash-studio-android-component-reviews-v1`，与桌面工坊及旧安卓主题编辑器独立保存。导出的安卓布局 CSS 用于对应安卓页面，接入源码后仍需在真机复核。

网络数据为本地样例，浏览器预览不接入 Tauri 模拟桌面宿主，不执行真实 VPN、相机、系统照片选择或权限授权；这些系统界面需在安卓设备验证。预览偏好写入仍隔离在 iframe 内存中。

`node scripts/verify-android-components.cjs` 检查全部 47 个目标的打开和实际中心坐标定位，另检查五种设备预设、自由宽高、平板布局等级、存储隔离、锁定持久化、坐标导出及请求隔离。测试报告在 `test-output/android-component-catalogue-report.json`。

## 以客户端源码为基准

默认“客户端原位”在 iframe 中直接加载当前 `Client.vue`、正式样式入口、主题和背景初始化代码。目录选择会跳到对应正式页面并描边标记目标，保留实际父级选择器、卡片间距、两列比例与 Dock。窗口宽度支持 1000、1280、1440 px；“缩放适应”只缩放显示，iframe 内的 CSS 布局视口仍为选择的桌面尺寸，高度为 860 px。

原位预览使用本地样例数据，不连接桌面实例，不提供真实代理、VPN、订阅刷新或删除操作。主题和背景沿用当前浏览器来源已有的设置，预览期间 localStorage 写入保存在 iframe 的内存副本中。工坊使用官方 Tauri mocks 展示桌面专属设置和窗口控件，原生调用仅返回本地样例，不执行系统操作；操作系统合成效果不由 iframe 模拟。浏览器与 Tauri 桌面来源的配置可能不同，已安装的旧发行包若与当前源码不同，须在相同构建版本中另行核对。

## 当前目录

目录共 61 项，按概览、订阅、模块、代理、连接、配置工作台、设置七个页面分组，可搜索名称、源码及说明。59 项可定位到客户端原位目标，另有下拉选择和分页两个基础组件。切换目录会自动打开对应页面、标签或弹窗并选中目标，随后可以选择其中任意可见元素。

覆盖各页工具栏、卡片、列表、节点、详情与分页，配置工作台的六个标签页及创建/发布等弹窗，以及设置页的外观、背景、端口、网络、行为、内核和日志等板块。全局顶栏与 Dock 也有独立入口。以下为复用组件来源：

- 内核与接管：`KernelControl.vue`。
- 内存占用：`ResourceMemoryView.vue`；采样容器为 `ResourceMemory.vue`。
- 方案选择：`OverviewSelection.vue`。
- 实时速率、网络出口：`NetworkDashboard.vue` 的两个实际卡片，当前只提供原位预览。
- 已启用模块：`EnabledModulesCard.vue`，当前只提供原位预览。
- 当前配置：`CurrentConfigCard.vue`，对应概览的紧凑卡片。
- 订阅卡片：`SubscriptionCard.vue`，对应订阅页完整卡片，内部包含 `SubscriptionUsage.vue`。
- 下拉选择、列表分页：基础组件，当前只提供单独预览。

单独预览用于细节状态测试；原位预览用于最终布局复核。不能把单独预览卡片的任意宽度当作正式页面中的实际宽度。原位模式只展示已接入数据场景；“应用中”等纯组件状态仍可在单独预览中测试。

## 逐块打磨与确认

### 安卓尺寸落地

用户提供的 `clashstudioandriod.json` 原始 15 条规则保存在 `frontend/src/component-lab/presets/android-user-layout.json`。393×873 视口下，订阅卡片及添加入口为 342×220，DNS/IPv6 弹窗为 377×360，规则编辑弹窗为 377×441，订阅导入弹窗为 377×472。正式样式在 `android-compact.css`，使用组件类名定位；窄屏以可用宽高为上限，弹窗主体滚动，内部不沿用容易重叠的固定负位移和子容器高度。

安卓页不渲染 `header.desk-topbar`，品牌入口独立排列；桌面顶栏保留。首次打开新工坊时，仅移除与已落地原始规则完全一致的旧覆盖项，并把原规则备份到 `clash-android-component-layout-v1-before-compact-v1`；其他用户修改保留。该迁移不会覆盖下载目录的文件。

### 实时调整位置与大小

画布上方和左侧提供像素刻度尺，原点是预览区域左上角，数值为真实 CSS 像素；缩放只改变刻度在屏幕上的间距。选中元素后，粉色虚线标出四条边界，刻度尺高亮所占范围，工具栏显示相对画布的坐标；这些坐标与元素属性中的 X/Y 视觉偏移分别显示。可开启“10 px 网格”辅助放置，网格目前仅作视觉参考，不强制吸附。刻度和参考线不写入布局规则或导出的正式页面 CSS。

工坊默认启用“选择 / 拖动”。点击页面上的卡片、文字、按钮、图标或容器即可选择；直接拖动选中的元素，或拖动选框上方的蓝色“拖动”标签改变视觉位置。八个边角手柄改变元素宽高，元素宽高参与实际页面排版。缩放后的画布会自动换算鼠标坐标。

在属性面板中输入 X、Y、元素宽度和高度会即时生效；方向键移动 1 px，Shift 加方向键移动 10 px。可以通过元素图层精确选择被遮挡或嵌套的节点，使用“选中父级”选择容器。“交互预览”退出编辑拦截，可正常查看控件交互。组件锁定后禁止布局编辑，解锁后继续。

选中元素后显示中心 X/Y 和青色中心十字，可直接输入中心坐标定位，支持 0.1 px 精度。中心取当前元素包围矩形的中点；原位模式以 iframe 可视区域左上角为原点，滚动会实时更新；单独预览以组件画布左上角为原点。显示缩放不改变坐标数值。中心坐标与 CSS 的 X/Y 视觉偏移是不同数值。

“复制中心坐标”复制当前元素的中心、单位和原点信息；“导出本页元素坐标 CSV”导出当前已渲染图层的选择器、中心 X/Y、宽度与高度。图层下拉列表也显示中心坐标，便于定位被遮挡的节点；未打开的弹窗和未渲染的分页内容不计入本页坐标导出。

“自定义窗口宽度”和“窗口高度”接受任意正整数像素；原位画布右下角的蓝色手柄可以直接拖动改变视口宽高。原先的 1000/1280/1440 宽度保留为快捷预设。高度默认 860 px，输入或拖动后使用自定义值；窗口尺寸改变不会重载 iframe，媒体查询与布局实时重新计算。单独预览提供自由容器宽度，元素自身的高度通过尺寸手柄或属性面板调整。

### 删除和恢复元素

选中元素后点击“删除元素”，或在画布按 Delete，元素及其占用空间会从预览中移除。“已删除元素”列表支持逐项恢复，也可撤销/重做；删除状态自动保存，并包含在布局 JSON 和 CSS 导出中。允许删除整个卡片或其内部节点，画布根节点不可删除。锁定组件或处于“交互预览”时不可删除或恢复。输入框编辑时 Delete 保留正常文本编辑行为。

删除使用 `display:none` 布局规则，保留 Vue 管理的 DOM、业务数据及结构定位，避免删除节点后路径错位；不等同于删除订阅、分流规则等业务内容。导入带有隐藏规则的布局后，也可通过列表恢复。`node scripts/verify-android-compact.cjs` 检查尺寸迁移、顶栏、短视口、删除/恢复、快捷键、锁定保护及导出。

### 字体与文字排版

选中标题、正文、按钮或容器后，“字体与文字排版”面板读取当前计算样式。可以实时调整字号、行高、字距、首行缩进（CSS px），选择字重、字体、对齐、空白处理、长词换行和横向/纵向排版。设置容器时，子元素按 CSS 继承规则响应；已有独立字号的子元素需要单独选择调整。字体列表提供系统、无衬线、衬线和等宽字体，具体字形取决于设备已安装字体。

清空数值移除该属性覆盖；“重置文字样式”仅移除文字属性，保留元素位置、尺寸等修改。文字调整与布局共用撤销/重做、浏览器保存、锁定、JSON 和 CSS 导出；重新导入后可以继续调整。排版导致文字溢出时，可配合元素尺寸和换行设置调整。`node scripts/verify-component-typography.cjs` 验证字体的实际计算结果、重置保留位置、持久化、导入导出、锁定及桌面/安卓/单独预览。

第二份 `clash-component-layout (1).json` 的 16 条记录保存在 `frontend/src/component-lab/presets/android-spacing-layout.json`，已应用品牌入口隐藏、订阅/代理间距和连接页标题区。订阅标题使用左对齐替代只适用于 393 px 的 -147 px 位移；连接页操作按钮独立排在标题右侧。旧覆盖项按完全匹配迁移，备份键为 `clash-android-component-layout-v1-before-spacing-v1`，其他后续修改保留。

### 跨状态样式与规则分页

最新 `clash-component-layout (2).json` 的 7 条位置记录保存在 `frontend/src/component-lab/presets/android-position-layout.json`。概览的标题和内容，以及订阅、代理、连接、设置的页面主体向右移动 6.9 CSS px；分流页没有此偏移。采用页面语义类名，保留正常和异常状态间的一致位置。完全匹配的旧工坊规则迁移前备份至 `clash-android-component-layout-v1-before-position-v1`，其余规则保留。

第三份导出的 18 条记录保存在 `frontend/src/component-lab/presets/android-state-layout.json`。内核卡片、三个分流模式按钮、语言卡片及规则操作行使用语义类名统一样式，不依赖正常状态下的节点顺序；布局和字体规则本身也在同一页面的所有状态中共用。内核卡片以 342×182、模式按钮以 77×40 为基准，小屏可收缩，运行提示、全局/直连说明和失败信息允许自然增高；语言卡片以 347×135 为基准，长文本允许增高。保存栏以 315 px 宽度居中，按导航栏预留底部间距，不沿用固定屏幕坐标；规则列表改为内容高度，不沿用 3328 px 固定高度。原覆盖项的迁移备份键为 `clash-android-component-layout-v1-before-state-v1`。

精确分流默认每页 5 条，可切换 10/20 条。搜索和筛选作用于全部规则，条目序号保持完整规则集中的优先级。上下移动可跨页并跟随移动后的规则；拖动只在本页可见条目间进行。删除末页会自动调整页码，保存和失败重试始终处理完整规则集。页码和每页条数随页面视图保留，切换订阅时重置页码。新增分页入口可单独打磨控件。

内核预览包括待启动、运行中、应用中、待应用、应用失败、未导入、全局和直连；规则列表提供正常、空列表、加载中、读取失败与 237 条规则场景；语言卡片提供中文和英文。业务操作仍为本地样例。“应用中”使用挂起的本地请求，“应用失败”使用本地错误响应，均不调用实际系统服务。

客户端、弹窗、列表及工坊使用共享 `scrollbars.css`，提供细滚动条、圆角滑块、透明轨道和主题颜色，悬停增强可见度。`node scripts/verify-android-states-pagination.cjs` 检查跨状态样式、分页筛选、跨页移动、完整保存、失败重试、末页删除、视图保留及滚动条计算样式。

修改自动保存在当前浏览器来源的 `clash-component-layout-v1` 中，刷新及切换场景后仍会应用。支持撤销、重做和重置当前元素。布局 JSON 包含全部布局规则和当前画布尺寸，可以导出、导入；CSS 导出包含客户端原位规则，单独预览规则保存在 JSON 中。导出的规则按页面和 DOM 结构路径定位，在正式样式之后加载才会生效；源码结构变更后需要复核定位。工坊不会自动修改源码。

1. 在正式页面原位选定一个组件，核对位置、宽度、主题及相邻卡片。
2. 切换已接入的状态，必要时切到单独预览检查边界和禁用状态；再回原位复核。
3. 记录调整意见，用户确认满意后点击“确认满意并锁定”。锁定表示人工验收约定，不能阻止源码或共享 CSS 修改。
4. 导出验收 JSON 留档。记录保存在当前来源的 localStorage v2，不跨端口、浏览器或桌面来源共享。首版 v1 标记不自动迁移，避免把不同结构的旧样例误当成已验收组件。
5. 变更已确认组件或其共享样式时，先明确影响，再解锁复核；需团队共享的结论应写入版本控制中的验收文档。

目录维护在 `frontend/src/component-lab/catalogue.ts`，单独预览由 `Lab.vue` 提供数据，原位桥接为 `frame.ts`，传输样例复用 `ui-editor/preview.ts`。后者仅在专用 frame 路径启用工坊场景，不改变正式客户端 API 实现。禁止复制一份正式组件模板来制作“相似”的工坊组件。

## 验证

最新订阅页坐标以 `clash-element-coordinates.csv` 为准：订阅卡片和添加订阅卡片均以 380×260 px 排版，覆盖此前 380×421 px 的订阅卡片基准。无订阅时使用同一个网格添加入口，长文本和错误信息按内容增高。
