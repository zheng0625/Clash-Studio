## 接口兼容与使用

- 桌面 POST /api/client/runtime/apply?background=true 和 stop?background=true 返回 HTTP 202，含 operation_id、kind 和 phase；原同步调用保留。
- GET /api/client/operations/{id} 返回 queued / running / succeeded / failed / cancelled；成功结果在 result，失败信息在 error。
- DELETE /api/client/operations/{id} 登记取消意图；实际资源收尾仍串行执行。取消某个旧操作不会误伤后续操作。
- GET /api/client/diagnostics 返回缓存、当前阶段、回滚结果、队列及最近最多 256 次请求的耗时分位数。Android 返回生命周期阶段、排队数及 storage_cleanup_pending。
- 前端桌面启动和停止使用异步任务轮询，启动中可停止；Android 保持原生桥直接响应，避免把带阶段字段的原生状态误判为桌面任务。
- 桌面采样时间为 Unix 秒数，Android 为 ISO 时间；前端兼容两者，拒绝把过期速率样本当作实时值。

## 合成性能记录

原始输出位于 artifacts/backend-benchmark.json，复现脚本为 scripts/benchmark-backend.py。开启 tracemalloc，配置每种规模执行 3 次；因此不能直接与原审查未使用相同采样方式的数字比较，也不能推断真实设备的网络性能。

| 场景 | 无缓存中位数 | 缓存命中中位数 | 完整合成次数 |
| --- | --- | --- | --- |
| 50 节点 / 501 规则 | 445.272 ms | 0.554 ms | 连续 3 次由 3 次降为 0 次；首次冷合成仍需 1 次 |
| 200 节点 / 3001 规则 | 2208.916 ms | 2.602 ms | 同上；配置版本改变重新合成 |

5000 条合成连接、同窗口两次流量和两次连接视图请求：完整采样由 4 次减少为 1 次，模拟内核响应字节由 1,904,712 减至 476,178。包含解析、结果生成与连接编码的单批主机耗时由 177.606 ms 降至 123.400 ms，tracemalloc 峰值由 5,836,067 降至 5,247,275 字节。该项只有一个批次，不包含真实 HTTP 往返，不是端到端延迟承诺。

生命周期锁被占用时读取状态 200 次，本机 P50 为 0.040 ms、P95 为 0.046 ms。这是方法级合成测量，不含 HTTP、桥接或 Android 原生开销；运行中的接口指标由 diagnostics 另行采样。

## 设备验收补充与剩余范围

1. Android 生命周期已完成真机补充：quickSetup 后延迟 96 秒、节点恢复后取消、回调交付延迟 40 秒、真实 90 秒超时、连续重启、系统撤销授权、Activity 重建及前后台切换均通过。
2. Android 并发已完成真机补充，指标和原始结果见设备记录。真实磁盘满、断电和旧大库迁移中断仍需独立文件系统级验收，未破坏用户手机数据进行测试。
3. Linux/Windows：有权限的 TUN 迁移、提权助手失效和真实系统代理恢复，需要目标系统网络验收。本机自动化只启用临时回环内核，未开启真实 TUN 或系统代理接管。

已通过的 Android 场景与仍未覆盖的桌面 TUN / 磁盘故障场景分别记录，没有将后者标记为通过。
