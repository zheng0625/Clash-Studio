## 3. 后端合成基准（不是客户端总内存）

| 场景 | 指标 | 结果 |
| --- | --- | --- |
| 200 节点 / 3,001 规则，未缓存 | 中位耗时 / 峰值 | 约 2.2 s / 7.0 MB |
| 同上，缓存热命中 | 中位耗时 / 峰值 | 2.6 ms / 84,952 B |
| 5,000 连接共享快照 | 耗时 / 峰值 / 传输 | 61–67 ms / 3,528,715 B / 476,178 B |
| 16 个版本键 / 8 MiB 预算 | 条目 / 估算字节 / 淘汰 | 8 / 4,177,500 B / 8 |
| 停止后 | 对象 / 编码字节 / 会话 / 累计流量 | 全部释放 / 保留 |

热命中与 0.9 秒快照是既有能力；新增的是缓存预算、等待边界、停止清理与少一次深拷贝。没有 Release RSS 对比，因此不填写百分比。

## 8. 风险与回退

- 严格 300 槽位会让部分组显示 0 节点，需折叠其他组；已加提示和浏览器验证。
- 代理目录 5 秒复用可能让外部节点变化延迟最多 5 秒；切换订阅、配置版本变化、显式刷新立即失效。
- 缓存饱和返回 503；默认 30 秒等待、8 个准入等待者与 16 个同键等待者上限，可按实测调整。
- `shallowRef` 仅用于整表替换、只读消费的连接列表；节点目录仍保留深层响应式以支持乐观选择。
- 浏览器验收为 Dev Vite；WebView2、GPU 合成与原生隐藏仍需 Release 验证。

## 9. 结论

已修复复核确认的四个缺陷，补齐采样口径、非概览曲线、可还原基线和浏览器 DOM 证据；缓存、连接、列表和预览都有明确上限或释放路径。**仍不能声称客户端总内存下降某个百分比或达到 20% 目标**。
