# 项目声明

Clash Studio 是面向 Windows、Linux 和 Android 的独立开源 Mihomo 客户端。项目以可视化订阅编辑、模块化管理和精准分流为核心，让源订阅、个人修改与实际运行配置形成可检查的工作流程。

## 项目定位

通过域名、进程、IP 网段等条件，为被内核接管的流量选择策略组或出口，并通过连接列表中的规则命中和流量数据核对配置。桌面端提供模块组合、规则排序和出口审查；Android 端以订阅管理、配置编辑、节点选择和 VPN 接管为主，各平台能力以实际界面和平台说明为准。

界面采用 Liquid Glass 风格的层次、悬浮 Dock 与统一卡片布局，配色及照片背景可按个人习惯调整。视觉设计服务于配置管理和日常使用，项目名称、图形界面与功能实现不代表任何上游项目的官方产品。

## 版本与平台

1.0 为正式版迭代起点，构建版本统一为 `1.0.0`。本次提供 Windows x64 便携版及安装版、Linux x64 包、Android arm64-v8a APK。Linux 以 Ubuntu 22.04 为构建基线；Android 最低支持 Android 8.0。其他系统和架构尚未提供本次发行包。

正式版标识说明版本阶段，不代表所有设备、网络与订阅组合均已验收。已执行的构建、自动检查及未覆盖范围见 [1.0 验证说明](validation-1.0.md)。Windows 安装包未签名；Android 使用独立正式签名，旧调试版需先导出配置、卸载后再安装，详见 [Android 签名说明](android-release-signing.md)。

## 数据与网络行为

源订阅、个人修改、模块组合和运行配置分别管理；未发布草稿不会直接成为运行配置。订阅链接、节点凭据和配置文件可能包含敏感信息，分享配置、日志或问题截图前应自行脱敏。示例与项目截图使用演示配置。

本机保存配置并不意味着全程离线。订阅导入与刷新、节点测速、IP 与归属地查询、GeoData 更新以及订阅引用的远程规则或服务，会按相应功能访问外部网络。开启代理或 VPN 后，相关流量按用户配置由所选出口处理。

## 功能边界

精准分流依赖流量是否被接管、进程信息是否可识别、规则顺序和内核支持。桌面系统代理与 TUN、Android VPN 的覆盖范围和权限要求不同；不能以某个平台的能力推断其他平台具备相同能力。

严格出口审查用于检查当前可见的配置关系，不保证固定公网 IP，不构成匿名性承诺，也不提供内核退出后的防火墙断网保护。桌面登录自启仅启动应用，网络接管仍需主动启动内核。

项目不提供代理服务、节点账号或可用订阅，用户需自行配置服务来源。
