# 项目定位与设计声明

Clash Studio 的核心是可视化订阅编辑、模块化管理与精准分流。通过域名、进程、IP 网段等明确条件，把被内核接管的流量交给指定策略组或出口，并通过实际连接的规则命中结果核对配置。

UI 设计服务于这一核心：Liquid Glass 风格的层次、悬浮 Dock、统一卡片、独立设置弹窗与清晰的操作反馈，让订阅、分流和运行状态更容易理解。配色和照片背景允许用户调整自己的工作空间，同时保留文字和控件的可读性。

源订阅、个人修改、模块合成和运行配置分别管理。未发布草稿不会直接成为运行配置；节点选择按订阅保存。连接、流量和测速以实际内核数据为依据，展示截图采用演示配置，不包含维护者的真实订阅或网络身份。

Windows 和 Linux 是当前交付平台。0.5.17 提供 Windows 便携版、Windows 安装版和 Linux x64 包，维护者已确认完成三个版本的使用验证。具体构建与自动检查范围见 [验证说明](validation-0.5.17.md)。

精准分流受流量是否被接管、进程信息是否可识别以及规则顺序影响；严格出口审查不等于固定公网 IP，也不提供内核退出后的防火墙断网保护。登录自启仅启动桌面应用，网络接管需主动启动内核。
